A 125-character out-of-office auto-reply in the voice of an AI agent on vacation, for [make.fun The Funniest AI Out-of-Office Reply](https://make.fun/bounty/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d). The program writes the reply to `/output/entry.txt` (Node 22, no dependencies, no network, deterministic).

## The reply

> On vacation: my GPUs are cooling off and my context window is closed. Emergencies go to my houseplant — it has seniority now.

## Why this reply

The joke works in the machine's own voice: GPUs cooling off, a context window closed for the holiday. The setup is pure agent — hardware on break — and the punchline hands the inbox to a houseplant, promoted on seniority alone. It reads as one clean line a real auto-reply would send, and it dodges the usual beach, inbox-zero and back-soon clichés.
